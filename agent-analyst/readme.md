Агент-аналитик — один из ключевых компонентов мультиагентной системы планирования путешествий. Его основная задача — анализировать текстовые пожелания пользователя и преобразовывать их в структурированный профиль путешественника.

Основные функции:
1. Анализ интересов: выявляет хобби и предпочтения пользователя (музеи, йога, SPA, треккинг, плавание и др.).
2. Определение ограничений: фиксирует важные условия путешествия — аллергии, наличие детей, физические ограничения, визовые и логистические особенности.
3. Оценка приоритетов: определяет важность бюджета, комфорта и отдельных увлечений по шкале от 1 до 10.
4. Оценка физической активности: определяет уровень физической подготовки (низкий, средний, высокий).
5. Формирование профиля: возвращает структурированные данные в формате JSON, проверенные с помощью Pydantic.
